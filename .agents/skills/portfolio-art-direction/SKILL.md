# Objetivo
Garantizar una identidad visual cohesiva, sobria y profesional para reclutadores, inspirada en un centro de recuperación y diagnóstico forense de datos.

# Instrucciones
1. **Paleta y Tema:** Tema oscuro estricto con fondos profundos (`#07090e`, `#0c111a`), superficies elevadas y un único color de acento: cian forense de alta visibilidad (`#00f0ff`).
2. **Tokens CSS:** Centralizar variables en `:root` dentro de `css/tokens.css` para colores, espaciados, tipografías, radios y sombras.
3. **Jerarquía Tipográfica:** Tipografía monoespaciada (`JetBrains Mono`, `Consolas`, monospace) para estados técnicos, badges, hashes LBA y terminal; tipografía sans moderna (`Plus Jakarta Sans`, `Inter`, sans-serif) para títulos y bloques de lectura.
4. **Accesibilidad de Movimiento:** Configurar soporte estricto para `prefers-reduced-motion: reduce`, desactivando transiciones o simplificándolas inmediatamente.
5. **Estilo Profesional:** Mantener una estética técnica pero pulida, evitando sobrecargar la pantalla con elementos distractores.

# Restricciones
- Máximo un solo color de acento cromático.
- Prohibidos parpadeos agresivos, animaciones infinitas intrusivas y sonidos automáticos.
