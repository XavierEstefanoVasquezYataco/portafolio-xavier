# Objetivo
Garantizar tiempos de carga ultrarrápidos (< 1s LCP), recursos optimizados y presencia profesional impecable en motores de búsqueda y redes sociales.

# Instrucciones
1. **Optimización Multimedia:** Formatos modernos de imagen (WebP o SVG vectorial), dimensiones fijas explícitas y carga diferida (`loading="lazy"`).
2. **Metadatos y Redes Sociales:**
   - Meta tags esenciales (`title`, `description`, `viewport`, `robots`, `theme-color`).
   - Etiquetas Open Graph (`og:title`, `og:description`, `og:image`, `og:url`, `og:locale`).
   - Favicon vectorial en SVG para máxima nitidez y peso despreciable.
3. **Datos Estructurados:** Esquema JSON-LD de tipo `Person` (Schema.org) detallando nombre, institución educativa (UTP), rol y conocimientos técnicos.
4. **Eficiencia en Carga:** Minimizar JavaScript externo, aplicar `font-display: swap` y preconexiones de DNS para fuentes.

# Restricciones
- Ningún script bloqueante que reduzca el First Contentful Paint.
- No incluir meta tags genéricos o vacíos.
